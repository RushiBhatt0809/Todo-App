# 📝 Todo App

A simple Todo app built with **React** and **Tailwind CSS**. Tasks are saved in localStorage so they persist on page refresh.

## Features

- Add, complete, and delete tasks
- Tasks saved in localStorage
- Input auto-focuses on load and after adding a task
- Press **Enter** to add a task

## Tech Stack

- React 18
- Tailwind CSS v4
- Vite

## Getting Started

```bash
npm install
npm run dev
```
